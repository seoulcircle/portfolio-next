# Home (studio landing)

Scope: `/[locale]` home. Visitor mode: Persuade. Audience: startups, institutions/exhibitions, brands evaluating the studio. Action: email inquiry. Proof: studio projects (client work images pending from user; slots labeled until supplied).

## Direction contract

THESIS: The studio is a clock. The hero's three lines of type are the hour, minute and second hands, turning on one red pivot in real Seoul time. Refuses the category default of a static giant wordmark over a thumbnail grid.

OWN-WORLD: White ground, black ink, one red pivot dot (#E0392B) as the only color outside project imagery. Light neo-grotesk (Helvetica Neue register, user-pinned), lowercase display, no rules, no cards, no shadows. Everything else on the page is a dial: numbered positions 01–12, hairline tick marks only where they measure something.

STORY: Visitor sees the brand literally keeping time, reads "studio / seoul circle / Designing and building digital experiences.", learns the three pillars, scans work, reads the founder note, emails.

FIRST VIEWPORT: Full-viewport white. Centered nav (home · work · about · contact) top. Red pivot at center; "studio" = hour hand, "seoul circle" = minute hand, tagline = second hand (reads inward, ticks every second). Text is left upside-down when a hand passes the left half (user decision). Bottom-left "Strategy · UX/UI · Development"; bottom-right "contact" email link as primary action; KO/EN top-right.

FORM: User-pinned clock frame (Frame 3), overriding the roll; seed key e9210fe0 (re-roll 1 abandoned for the user's direction).
